# TANIA77 Landing Page

File:
- index.html
- style.css
- hero.jpg (tambahkan gambar banner milik kamu)

## Cara pakai
1. Letakkan `index.html`, `style.css`, dan `hero.jpg` dalam folder yang sama.
2. Buka `index.html` untuk preview.
3. Di `index.html`, ganti:
   - `https://contoh-login.com` dengan link LOGIN kamu.
   - `https://contoh-daftar.com` dengan link DAFTAR kamu.
4. Upload ketiga file ke GitHub Pages.

Desain dibuat responsif untuk tampilan HP seperti screenshot.
